# GICS 一级行业（Global Industry Classification Standard）

这是全球最主流的行业分类标准，由：

- MSCI
- S&P Global

联合制定。

广泛用于：

- 标普500
- MSCI指数
- 全球ETF
- 基金行业配置
- 机构投资研究

------

| 一级行业 | 英文                   | 核心内容                 |
| -------- | ---------------------- | ------------------------ |
| 能源     | Energy                 | 石油、天然气、能源开采   |

| 金融     | Financials             | 银行、保险、券商         |
| 信息技术 | Information Technology | 软件、芯片、AI、硬件     |

# 最核心的一句话

GICS 本质上是在回答：

```plain
全球资本市场的钱
到底投向哪些产业
```

所以：

- ETF
- 行业基金
- 宏观配置
- 全球资产配置

基本都会围绕：

```plain
GICS 一级行业
```

来展开。
