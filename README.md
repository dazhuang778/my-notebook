# my-notebook

个人技术学习与投资研究的知识笔记库，持续更新，定期同步至远程仓库。

## 项目背景

在日常学习与投资研究过程中，零散的知识点容易遗忘，建立这个仓库的初衷是：

- 通过书写强化理解，记录思考过程
- 建立结构化的个人知识体系
- 方便日后复习检索，避免重复踩坑

---

## 目录结构

```
NoteBook/
├── Investment/         # 投资研究
│   ├── Stock/          # 股票分析与个股研究
│   ├── Fund/           # 基金、ETF 与指数基金
│   ├── Crypto/         # 加密货币
│   ├── Macro/          # 宏观经济与市场分析
│   └── Books/          # 投资相关书籍笔记
└── AI-ML/              # 人工智能与机器学习
```

## 目录说明

| 目录 | 说明 |
|------|------|
| `Investment/Stock` | 股票分析方法、行业研究、个股笔记 |
| `Investment/Fund` | 基金投资策略、ETF 与指数基金研究 |
| `Investment/Crypto` | 区块链基础、加密货币市场分析 |
| `Investment/Macro` | 货币政策、经济周期、全球市场分析 |
| `Investment/Books` | 投资类书籍的读书笔记与核心摘录 |
| `AI-ML` | 机器学习、深度学习、大模型、Prompt 技巧 |
